# รายการที่ผู้ใช้ต้องลองด้วยตา (รายละเอียดเต็ม)

STATE.md ชี้มาที่ไฟล์นี้ ข้อ 6-12 ของ "รอผู้ใช้ทำ" (เลขข้อตรงกัน)

6. งาน 2026-10-21 push แล้ว (c5f1fa6, 5a9d79a, 0215a48, 79263cd, 3262ca2) รอผู้ใช้ลองใน LINE/เบราว์เซอร์: ปุ่ม วิธีใช้งาน ควรได้ปุ่มลอย 13 ปุ่มขึ้นต้นด้วย emoji และ emoji แสดงสวยไหม; พิมพ์ สรุปวันนี้ กับ ซื้อของ ให้ Claude ตอบเป็นเสียงเฮีย; หน้าย่อยแท็บ ฉัน หัวข้อซ้ำหายและแถวเมนูไม่กระโดดตอนโหลด; error ใน dialog เลื่อนให้เห็นบนมือถือ
7. ปุ่มย้อนกลับของเครื่องในหน้าย่อย (P3 ข้อ 1, 2026-10-21): หน้าย่อยเพิ่ม history 1 รายการ ย้อนแล้วกลับแท็บเจ้าของหน้าแทนออก LIFF (app.mjs: pushSubPageEntry, popstate); ทดสอบด้วย jsdom เท่านั้น รอผู้ใช้ลองบน Android/iOS จริงว่า LIFF ไม่ดักปุ่มย้อนกลับเอง
8. งบเฟส 1 ต้องลองด้วยตาใน LIFF (ผู้ใช้เปิดแอปเอง): (ก) แท็บ งบ มีแผงน้ำเงิน % ตัวใหญ่ แท่งสูงเท่ากัน เส้นประพาดหัวแท่ง ส่วนเกินสีแดงเหนือเส้น แตะแท่งเปิด dialog แก้งบ ท้ายหน้ามีการ์ด ปกติ/ยังไม่ตั้งงบ/จัดการหมวดหมู่; (ข) บัญชีไม่มีงบเห็นการ์ด ยังไม่ได้ตั้งงบเลย และปุ่ม ตั้งงบ ปิดเน็ตเห็น ลองใหม่; (ค) ดูทั้งหมด: 3 แท็บ ค้นหา ล้างคำค้น แตะแถวแก้งบ ปุ่มย้อนกลับ (รวมของเครื่อง) กลับหน้างบ
9. งบเฟส 2 ลองด้วยตาใน LIFF (ผู้ใช้เปิดแอปเอง ต้องมีหมวดเกินงบ 1 หมวดและหมวดไม่ตั้งงบ 1 หมวด): แตะแท่งหมวดเกินงบ ได้แผ่นเลื่อนขึ้นจากล่างพร้อมกรอบ "ตอนนี้ 115%" กับ "ถ้างบ ..."; กด + ได้ +500 และ % เปลี่ยนทันที; ปุ่มลัด เท่าที่ใช้จริง ได้ 100%; บันทึกแล้วแผ่นปิดและแท่งเปลี่ยน; หมวดไม่ตั้งงบ หัว "ตั้งงบ <ชื่อ>" กรอบเส้นประ ไม่มีปุ่ม ไม่ตั้งงบ; ไม่ตั้งงบ -> กล่องยืนยัน, กด ไม่ลบ แผ่นยังอยู่; ปิดเน็ตแล้วบันทึก เห็นกรอบแดง ตัวเลขยังอยู่ ปุ่มเป็น ลองบันทึกอีกครั้ง
10. งบเฟส 3 ลองด้วยตาใน LIFF บนมือถือจริง (ผู้ใช้เปิดแอปเอง): (ก) ดูทั้งหมด > ปุ่ม แก้งบหลายหมวดพร้อมกัน เปิดหน้าแก้ เรียง ต้องดูแล > ปกติ > ไม่มีงบ; กด + ได้ +500 แถวมีเส้นน้ำเงิน ขึ้น ก่อน% -> หลัง% แถบล่างสรุปรวม; หมวดไม่ตั้งงบกด + ได้ 500 ป้าย ใหม่; (ข) บันทึกทั้งหมด กลับดูทั้งหมดพร้อม "บันทึกงบแล้ว N หมวด"; (ค) ตัดเน็ตแล้วบันทึก ได้ dialog บันทึกไม่สำเร็จ ปิดเน็ตคืนแล้วกด ลองบันทึกหมวดที่ไม่สำเร็จ; (ง) ปุ่มย้อนกลับของเครื่อง/ปัดย้อนจากหน้าแก้หลายหมวด กลับดูทั้งหมด กดอีกครั้งกลับแท็บ งบ อีกครั้งออกตามปกติ
11. แท็บออม ดีไซน์ A ลองด้วยตาใน LIFF (ผู้ใช้เปิดแอปเอง): ด้านบนเป็นการ์ดน้ำเงิน ออมแล้วรวม N เป้า ยอดรวมตัวใหญ่ แท่งขาว X% ของเป้ารวม และ เหลืออีก (นับเฉพาะเป้าที่เปิด); แต่ละเป้าเป็นการ์ดขาว % ขวาตัวหนาสีน้ำเงิน, เป้าครบแล้วเป็นป้าย ครบแล้ว แท่งเขียว, ฝั่งขวาล่าง ถึงเป้า ... หรือ ไม่กำหนดวัน; กดการ์ดเปิดรายละเอียดเหมือนเดิม; ปิดแล้ว N เป้า อยู่ใต้รายการ; ปุ่ม สร้างเป้าใหม่ กรอบเส้นประกลางจอ; ตอนโหลดโครง skeleton ไม่ทำให้หน้ากระโดด
12. animation 10 ข้อ (แผน docs/superpowers/plans/archive/2026-10-21-motion-polish.md) ลองใน LINE แล้วบอกจุดที่ไม่สวย: ไอคอนแท็บเด้ง; รายการเลื่อนเข้าจากขวา; แผ่นล่างเด้งนุ่ม (กล่องยืนยันกลางจอซูม); แท่งงบตั้งโตจากล่าง แท่งนอนจากซ้าย; หน้าออมแท่งรวมเติมแล้วการ์ดตาม; หน้า ฉัน รูปเด้งแล้วเมนูตาม; หน้าสรุปแถบสีไหลเต็ม (เฉพาะตอนเข้าแท็บ สลับรายรับ/รายจ่ายไม่เล่น); ปุ่มเหลืองมีริบเปิลตอนแตะ; ข้อความ บันทึกงบแล้ว N หมวด / ยืนยันบิล / ส่งลิงก์บิลแล้ว มีเครื่องหมายถูกวาดนำหน้า; เปิดลดการเคลื่อนไหวแล้วต้องไม่มีอะไรขยับ
