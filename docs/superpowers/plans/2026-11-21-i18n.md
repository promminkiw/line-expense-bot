# เปลี่ยนภาษา (ไทย/อังกฤษ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ผู้ใช้เลือกภาษาไทยหรืออังกฤษได้เองทั้งในแชตและในเว็บ LIFF ค่าที่เลือกเก็บต่อผู้ใช้ใน `users.language` บอทและเว็บใช้ค่าเดียวกัน ข้อความทุกจุดที่ผู้ใช้เห็นมาจากชุดแปลชุดเดียว

**Architecture:** ชุดแปลเป็น ES module ข้อมูลล้วน `public/liff/i18n/messages/{th,en}.mjs` พร้อม `public/liff/i18n/translate.mjs` (`t(lang, key, params)`) เว็บ import ตรง ส่วนบอท (CommonJS) ใช้ `require()` ของ ESM ซึ่งเปิดเองใน Node 22.12+ (Render ใช้ 24.22.1, เครื่อง dev 26) จึงไม่มีสำเนาข้อความสองชุด ภาษาเก็บที่คอลัมน์ `users.language` (`th`/`en`, null = ยังไม่เลือก ถือเป็น `th`) อ่านมาพร้อม id ตอน resolve ผู้ใช้ จึงไม่เพิ่ม query ต่อข้อความ ชื่อหมวด/กระเป๋าใน DB คงเป็นไทย (SQL ใช้เป็น key) แปลตอนแสดงและตอนส่งให้ Claude เฉพาะชื่อตั้งต้นที่ผู้ใช้ยังไม่เปลี่ยน

**Tech Stack:** Node 24 CommonJS + require(esm), Express, @line/bot-sdk, LIFF SDK edge/2 (`liff.getAppLanguage()`), Supabase/Postgres, vitest, ESLint 9

**การตัดสินของผู้ใช้ (2026-11-21):**
- ภาษา: ไทย + อังกฤษ (โครงสร้างเพิ่มภาษาได้โดยเพิ่มไฟล์ใน `messages/` และค่าใน `SUPPORTED_LANGUAGES`)
- ค่าเริ่มต้นผู้ใช้ใหม่: ตามภาษาแอป LINE (`language` จาก Messaging API getProfile ตอนสมัคร หรือ `liff.getAppLanguage()` ตอนเปิดเว็บครั้งแรกถ้ายังเป็น null) ขึ้นต้นด้วย `en` = อังกฤษ อื่นๆ = ไทย
- บุคลิกภาษาอังกฤษ: ไม่มีชื่อ แทนตัวว่า I เรียกผู้ใช้ว่า you น้ำเสียงผู้ชายเป็นกันเอง ไม่เป็นทางการ
- ชื่อหมวด/กระเป๋า: DB คงชื่อไทย แปลตอนแสดงและตอนส่งให้ Claude เฉพาะชื่อตั้งต้น/ระบบที่ยังไม่ถูกเปลี่ยนชื่อ หมวดที่ผู้ใช้ตั้งเองแสดงตามที่ตั้ง

**ข้อจำกัดที่รู้แล้ว (นอกโค้ด ไม่อยู่ในแผนนี้):** Rich Menu เป็นรูปที่สร้างใน LINE OA Manager, Greeting message ของ LINE OA และชื่อแอป LIFF ใน LINE Developers ยังเป็นไทย ถ้าต้องการต้องทำ Rich Menu ต่อภาษาผ่าน Messaging API (`linkRichMenuToUser`) เป็นงานแยก
