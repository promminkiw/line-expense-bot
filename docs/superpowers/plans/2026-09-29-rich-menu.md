# Rich Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ทำขั้นที่ 5 ของ `SPEC.md`: มี Rich Menu 3 ปุ่ม `สรุป` / `เปิดเว็บ` / `ช่วยเหลือ` ใต้ห้องแชต โดยสร้างเมนูในเว็บ LINE Official Account Manager และให้บอทตอบข้อความของปุ่ม `ช่วยเหลือ` และ `เปิดเว็บ`

**Architecture:** ปุ่มทั้ง 3 เป็น action แบบส่งข้อความ (ผู้ใช้กดแล้วเหมือนพิมพ์เอง) ปุ่ม `สรุป` ส่ง `สรุป` ซึ่งบอทตอบได้อยู่แล้วจากขั้นที่ 4 ส่วน `ช่วยเหลือ` และ `เปิดเว็บ` ให้ไฟล์ใหม่ `src/menu/fixed-replies.js` จับคู่ข้อความกับคำตอบคงที่ บอทเช็คก่อนส่งให้ Claude จึงไม่เสียค่า API และไม่แตะบริบทที่จำไว้ ตัวเมนู (รูปและปุ่ม) ผู้ใช้สร้างเองบนเว็บ ไม่มีโค้ด

**Tech Stack:** Node.js 22 (CommonJS), @line/bot-sdk 11.2.0, Vitest 5.0.2, LINE Official Account Manager (เว็บ)

## Global Constraints

- ผู้ใช้ใช้ Windows; โปรเจกต์เป็น CommonJS; ไฟล์เทสต์ใช้ `import`; ห้าม `vi.mock` กับ module ที่ถูก `require`; เทสต์วางคู่กับไฟล์
- ไม่เพิ่ม dependency ใหม่
- คอมเมนต์ในโค้ดสั้น บรรทัดเดียว ภาษาไทย อธิบาย "ทำไม"; ชื่อตัวแปร/function/log เป็นภาษาอังกฤษ; ห้าม emoji ในโค้ด คอมเมนต์ log และ commit message
- ห้าม agent อ่านหรือแก้ `.env`; ห้าม agent start/restart/kill server
- Rich Menu สร้างในเว็บ LINE Official Account Manager (ผู้ใช้ทำเอง) แบบ 3 ช่องแนวนอน ปุ่มทุกปุ่มเป็น action ส่งข้อความ: `สรุป` → ข้อความ `สรุป`, `เปิดเว็บ` → ข้อความ `เปิดเว็บ`, `ช่วยเหลือ` → ข้อความ `ช่วยเหลือ`
- เทียบข้อความหลังตัดช่องว่างทั้งหมดออก (แบบเดียวกับคำสั่งสรุป)
- คำตอบของ `เปิดเว็บ` จนกว่าจะมี LIFF (ขั้นที่ 6): `หน้าเว็บสำหรับดูและแก้ไขรายการกำลังพัฒนา จะเปิดใช้ได้เร็วๆ นี้`
- คำตอบของ `ช่วยเหลือ` คือข้อความ `HELP_REPLY` ใน Task 1 ตามตัวอักษร
- ข้อความคงที่ตอบก่อนเช็ค rate limit และไม่เรียก Claude ไม่อ่านหรือแก้บริบทที่จำไว้ (pending clarification)

```js
const HELP_REPLY = [
  'วิธีใช้บอทบันทึกรายรับรายจ่าย',
  '- พิมพ์รายการได้เลย เช่น "กินข้าว 60 กาแฟ 45"',
  '- รายรับ เช่น "เงินเดือนเข้า 25000"',
  '- ย้อนวันได้ เช่น "เมื่อวานค่าแท็กซี่ 120"',
  '- บันทึกแล้วกดปุ่ม "ยกเลิก" ใต้ข้อความเพื่อลบรายการชุดนั้น',
  '- พิมพ์ "สรุป" หรือกดปุ่มสรุปในเมนู เพื่อดูยอดวันนี้ สัปดาห์นี้ หรือเดือนนี้',
  '- จำนวนเงินต่อรายการไม่เกิน 10,000,000 บาท',
].join('\n');

// ใช้จนกว่าจะมีหน้าเว็บ LIFF ในขั้นที่ 6 แล้วเปลี่ยนปุ่มให้เปิดลิงก์แทน
const WEB_COMING_SOON_REPLY = 'หน้าเว็บสำหรับดูและแก้ไขรายการกำลังพัฒนา จะเปิดใช้ได้เร็วๆ นี้';

const FIXED_REPLIES = {
  'ช่วยเหลือ': HELP_REPLY,
  'เปิดเว็บ': WEB_COMING_SOON_REPLY,
};

function getFixedReply(text) {
  const key = text.replace(/\s+/g, '');
  return Object.hasOwn(FIXED_REPLIES, key) ? FIXED_REPLIES[key] : null;
}

module.exports = { getFixedReply, HELP_REPLY, WEB_COMING_SOON_REPLY };
```
